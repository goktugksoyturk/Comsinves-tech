
# Comsinves

Comsinves is a portfolio tracking web application that enables users to monitor and analyze their investments across multiple asset classes — including cryptocurrencies, stocks, and funds — in a single, unified dashboard.

## 🌐 Live Demo

https://comsinves.tech

---

## 📊 Features

- **Multi-Asset Tracking**
  - Track cryptocurrencies, stocks, and ETFs in one place

- **Real-Time Pricing**
  - Live market data integration for accurate portfolio valuation

- **Portfolio Overview**
  - Total value, daily changes, and asset distribution

- **Performance Analytics**
  - Track portfolio growth over time with interactive charts

- **Insights**
  - Basic portfolio analysis including allocation and top performers

- **Authentication**
  - Secure user authentication using Google OAuth and email login

---

## 🧠 Key Challenges & Learnings

During development, several real-world challenges were addressed:

- Handling unreliable external APIs and ensuring graceful fallbacks  
- Managing authentication flows and redirect issues with Supabase  
- Designing a clean and usable financial dashboard UI  
- Structuring a scalable frontend with reusable components  
- Ensuring consistent data calculations across multiple asset types  

---

## 🛠 Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS  
- **Backend & Auth:** Supabase  
- **APIs:** Crypto and stock market data providers
